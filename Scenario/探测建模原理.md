# 声学 / 雷达异构探测建模原理

> **适用范围**：`Scenario/step2_detection_simulation.m`（Step2 v2.5）及 `acoustic_adaptive_R.m`  
> **上游数据**：`run_scenario.m` → `Step1_Data.mat`  
> **下游消费**：`main_imm_jpda_ekf.m` ← `detections_to_ZR.m`

---

## 1. 问题背景

城市低空多无人机跟踪场景中，地面部署两类异构传感器：

| 传感器 | 优势 | 劣势 |
|--------|------|------|
| **雷达** | 位置精度高（~1 m）、量测稳定 | 受建筑遮挡、RCS 敏感 |
| **声学阵列** | 可穿透遮挡、部署成本低 | 定位精度低、径向/切向误差各向异性 |

Step2 的任务是：给定 Step1 真值轨迹与传感器布局，逐帧生成符合物理规律的 `objectDetection` 点迹，供 IMM-JPDA-EKF 跟踪器消费。

```
Step1_Data.mat (truth, buildings, acousticPos, radarPos)
        │
        ▼
step2_detection_simulation.m
  ├── B. 雷达：MATLAB Radar Toolbox (radarDataGenerator)
  └── C. 声学：传播衰减 + Logistic Pd + 自适应 R + 遮挡
        │
        ▼
Step2_HeteroDetections.mat (allDetections)
        │
        ▼
detections_to_ZR.m → Z, R_list → JPDA 门控 / PDA 更新
```

## 2. 雷达探测建模

### 2.1 工具与接口

雷达探测采用 **MATLAB Sensor Fusion and Tracking Toolbox** 中的 `radarDataGenerator`，将每部雷达建模为独立探测器：

```matlab
radars{i} = radarDataGenerator( ...
    'SensorIndex',       100 + i,        % >100 用于与声学区分
    'UpdateRate',        1 / UAV.dt,     % 10 Hz
    'MountingLocation',  radarPos(i,:), ...
    'FieldOfView',       [120, 60],      % 方位 120°，俯仰 60°
    'RangeLimits',       [20, 1000],     % 有效距离 (m)
    'RangeResolution',   1.0,            % 距离分辨率 (m)
    'AzimuthResolution', 1.0,            % 方位分辨率 (°)
    'ReferenceRCS',      -12,            % 参考 RCS (dBsm)，小型无人机
    'HasElevation',      true, ...
    'FalseAlarmRate',    1e-6);
```

### 2.2 物理含义

**雷达方程（Toolbox 内部实现）** 将接收功率与目标 RCS、距离四次方衰减关联：

$$P_r \propto \frac{\sigma_{\mathrm{RCS}}}{R^4}$$

其中 $\sigma_{\mathrm{RCS}}$ 为目标雷达截面积。`ReferenceRCS = -12\ \mathrm{dBsm}$ 对应约 $0.063\ \mathrm{m}^2$，代表小型四旋翼无人机的典型值。

**量测生成**：每帧将活跃目标封装为 `targetPlatforms` 结构体（含 `Position`、`Velocity`、`Size`），调用 `radars{r}(targetPlatforms, currTime)` 得到 3D 位置量测及 Toolbox 内置的量测噪声协方差。

**速度字段**：v2.5 起使用 `truth.vel3D` 真值速度（旧版硬编码 `[10 5 0]` 已修复），影响多普勒相关量测质量。

### 2.3 遮挡后处理

Toolbox 本身不考虑城市建筑遮挡。Step2 在雷达输出后增加 **线段–AABB 相交测试**：

```
雷达位置 ──────────► 量测位置
         │
    若与任一建筑包围盒相交 → 丢弃该探测
```

实现：`isOccluded(p1, p2, buildings)` + `lineBoxIntersection`（参数化线段与轴对齐包围盒求交）。

### 2.4 输出格式

通过遮挡检测的雷达点迹附加：

```matlab
ObjectAttributes = struct('ClassConfidence', 0.65, 'SensorType', 'Radar');
```

跟踪器侧默认噪声（`config_tracker.m`）：

$$R_{\mathrm{radar}} = \mathrm{diag}([1^2,\ 1^2])\ \mathrm{m}^2$$

若 `objectDetection.MeasurementNoise` 有效，则 `detections_to_ZR` 优先使用量测自带噪声。

## 3. 声学探测建模

声学通道为 **自定义物理模型**，分四层：**传播衰减 → 检测概率 → 各向异性量测噪声 → 遮挡**。

### 3.1 声传播与 SNR

无人机旋翼噪声建模为固定声源级 $SL$，经球面扩散与空气吸收到达传感器：

$$\mathrm{recvLevel} = SL - 20\log_{10}(r) - \alpha \cdot r$$

| 参数 | 符号 | 默认值 | 含义 |
|------|------|--------|------|
| 声源级 | $SL$ | 110 dB | 无人机辐射噪声 |
| 背景噪声 | $N_{\mathrm{bg}}$ | 60 dB | 环境 SPL |
| 吸收系数 | $\alpha$ | 0.002 dB/m | 空气吸收 |
| 距离 | $r$ | — | 传感器–目标欧氏距离 (m) |

**信噪比**：

$$\mathrm{SNR} = \mathrm{recvLevel} - N_{\mathrm{bg}}$$

典型量级：$r=50\ \mathrm{m}$ 时 $\mathrm{recvLevel}\approx 110 - 34 - 0.1 \approx 76\ \mathrm{dB}$，$\mathrm{SNR}\approx 16\ \mathrm{dB}$；$r=200\ \mathrm{m}$ 时 $\mathrm{SNR}\approx 4\ \mathrm{dB}$。

### 3.2 检测概率（Logistic 模型）

采用连续 Logistic 函数替代硬门限，使 $P_d$ 随 SNR 平滑变化：

$$P_d(\mathrm{SNR}) = \frac{1}{1 + \exp\bigl(-(\mathrm{SNR} - \tau)\bigr)}$$

检测门限 $\tau = 3.5\ \mathrm{dB}$。每帧对每个（目标, 传感器）对以概率 $P_d$ 伯努利抽样决定是否产生点迹。

| SNR (dB) | $P_d$ |
|----------|-------|
| 0 | 0.03 |
| 3.5 | 0.50 |
| 10 | 0.998 |
| 16 | ≈1.0 |

### 3.3 自适应各向异性量测噪声（`acoustic_adaptive_R`）

声学定位误差在 **传感器–目标连线坐标系** 下分解为两个正交方向：

#### 切向误差（DOA / 方位估计）

基于 Cramér–Rao 界，方位标准差随 SNR 改善：

$$\sigma_\theta(\mathrm{SNR}) = \frac{\sigma_{\theta 0}}{\sqrt{\mathrm{SNR}_{\mathrm{lin}}}}$$

弧长误差（垂直于视线方向）：

$$\sigma_t = r \cdot \sigma_\theta(\mathrm{SNR})$$

默认 $\sigma_{\theta 0} = 8°$。

#### 径向误差（幅度测距）

声压幅度给出的距离估计误差：

$$\sigma_r = \frac{\sigma_{r 0} \cdot r}{\sqrt{\mathrm{SNR}_{\mathrm{lin}}}}$$

默认 $\sigma_{r 0} = 0.15$（无量纲系数）。径向误差通常比切向大 **约一个量级**。

#### 限幅与旋转

$$\sigma_{t,r} \leftarrow \mathrm{clip}(\sigma_{t,r},\ \sigma_{\min},\ \sigma_{\max})$$

默认 $\sigma_{\min}=2\ \mathrm{m}$，$\sigma_{\max}=50\ \mathrm{m}$。

设视线方位角 $\phi = \mathrm{atan2}(\Delta y, \Delta x)$，旋转矩阵 $R_\phi$ 将局部对角协方差映射到世界坐标系：

$$R_{2d} = R_\phi \begin{bmatrix} \sigma_r^2 & 0 \\ 0 & \sigma_t^2 \end{bmatrix} R_\phi^\top$$

**几何直觉**：

```
        切向 σ_t（小）
          ↑
          │    ╱ 视线方向
    传感器 ●────────► 目标
          径向 σ_r（大）
```

#### 垂直方向

声学高度估计能力差，$z$ 方向采用 **固定各向同性噪声**：

$$\sigma_z = 10\ \mathrm{m}, \quad R_{3d} = \mathrm{blkdiag}(R_{2d},\ \sigma_z^2)$$

量测采样：对 $R_{2d}$ 特征分解后按 $\mathcal{N}(\mathbf{0}, R_{2d})$ 采样水平噪声，叠加 $z$ 噪声。

### 3.4 遮挡

与雷达相同：传感器位置到 **真值目标位置**（非带噪量测）的连线若穿过建筑则抑制探测。声学穿透性在模型中体现为 **不额外衰减**，仅做几何 LOS 判断。

### 3.5 输出格式

```matlab
acDet = objectDetection(currTime, measPos', ...
    'SensorIndex', s, ...              % s ≤ numAcoustic，与雷达 100+i 区分
    'MeasurementNoise', R3d, ...
    'ObjectClassID', 1);
acDet.ObjectAttributes = struct( ...
    'ClassConfidence', max(0.3, min(0.95, Pd)), ...
    'SensorType',      'Acoustic', ...
    'SNR_dB',          snr);
```

## 4. 与跟踪系统的接口

### 4.1 传感器类型辨识

`plot_full_pipeline.m` 与 `detections_to_ZR.m` 通过 `SensorIndex` 区分：

| SensorIndex | 类型 |
|-------------|------|
| $1 \ldots N_{\mathrm{acoustic}}$ | 声学 |
| $> 100$ | 雷达 |

### 4.2 量测噪声传递链

```
Step2: R3d (3×3) 写入 objectDetection.MeasurementNoise
           │
           ▼
detections_to_ZR: 取 noise(1:2,1:2) → R_list(:,:,d)
           │         （正定检查，失败则回退 cfg.R_acoustic）
           ▼
jpda_gating: S = H P H' + R_d
ekf_pda_update: R̄ = Σ β_d R_d
```

**关键改进（v2.5）**：声学 $R$ 不再是固定 $\mathrm{diag}(8^2, 8^2)$，而是 **随距离与 SNR 变化的旋转椭圆**，更真实地反映 DOA 精度优于测距精度的物理事实。跟踪器门控与 PDA 更新会自动使用逐点自适应 $R$。

`config_tracker.m` 中 `R_acoustic = diag([8², 8²])` 仅作 **回退默认值**。

### 4.3 量测维度

跟踪器状态为 4D $[p_x, p_y, v_x, v_y]$，量测仅取 **水平位置** $(x, y)$；$z$ 分量在 `detections_to_ZR` 中被丢弃。

## 7. 设计要点与局限

**已实现**

- 雷达：Toolbox 物理模型 + 城市遮挡后处理
- 声学：传播衰减、Logistic $P_d$、CRB 启发的各向异性 $R$
- 异构点迹统一 `objectDetection` 封装，噪声随点迹携带
- 真值速度 `vel3D` 驱动雷达平台运动学

**已知简化**

- 声学未建模多径、风噪、频率选择性吸收
- 遮挡为硬 LOS（0/1），无衍射绕射
- 雷达 RCS 固定，未随姿态变化
- 声学 SNR 不随目标速度/高度细分声源模型
